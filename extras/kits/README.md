# VoidFlame Duels — Kit Presets

These files are separated copies of the kit definitions currently configured in `src/main/resources/config.yml`, for review and editing.

**Important:** they are VoidFlame project presets. They are not claimed to be exact exports of the PvPPrac — The Arsenal loadouts. The public PvPPrac page lists kit names and item counts, but its full per-slot item/effect payloads were not available through the accessible page content.

The plugin currently reads the active definitions from `src/main/resources/config.yml`; these files are reference/export copies and are not automatically loaded by the plugin.
